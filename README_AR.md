# ALMANTHOMH EO CN — الإصدار الأول 1.0.0

## ما الذي يتضمنه هذا الإصدار؟

- واجهة عربية RTL متجاوبة للموقع والهواتف.
- هوية ESKO: شعار النسر والخلفية البحرية.
- عرض 300 رقم خانة ضمن 6 مجموعات (50 لكل مجموعة).
- فحص اتصال الموقع وملف إعداد الإصدار عند فتح الواجهة.
- أساس PWA قابل للتثبيت من المتصفح بعد النشر عبر HTTPS.
- عناصر وصف ودليل استخدام وحالة خدمات ومركز تنزيل تجريبي.
- سكربت رفع إلى GitHub من Termux يطلب اسم المستخدم ثم التوكن دون إظهاره.

## ما الذي لم يُفعّل بعد؟

هذا الإصدار هو **إصدار واجهة وبنية تأسيسية** وليس منصة إنتاجية مكتملة. لا توجد بعد خدمة خلفية أو تطبيق Android مرافق. لذلك لا تنفذ الواجهة حجزًا حقيقيًا مشتركًا، أو تسجيل دخول سحابيًا، أو تحكمًا في الهاتف، أو إدارة حظر فعلية، أو APK للتنزيل. تُعرض هذه الحالات بصراحة بدل محاكاة نجاح غير حقيقي.

## النشر عبر GitHub Pages

1. أنشئ مستودع GitHub جديدًا باسم `ALMANTHOMH-EO-CN` (فارغًا دون README أو License أو .gitignore).
2. يُفضّل جعله عامًا إذا كنت تستخدم خطة GitHub Free وتريد نشر GitHub Pages.
3. من Termux انتقل إلى مجلد المشروع وشغّل `bash scripts/termux-upload.sh`.
4. أدخل اسم مستخدم GitHub، ثم Personal Access Token. سيتم إدخال التوكن دون إظهاره، ولن يُكتب داخل ملفات المشروع أو Git config.
5. بعد نجاح الرفع افتح Settings → Pages، واختر Deploy from a branch، ثم الفرع الذي يطبعه السكربت والمجلد `/docs`، واضغط Save.
6. انتظر ظهور رابط Pages في إعدادات المستودع.

## صلاحية التوكن

استخدم Personal Access Token مخصصًا للمستودع المقصود بصلاحية Contents: Read and write. إذا استخدمت Classic PAT، فيلزم نطاق `repo`. لا ترسل التوكن داخل المحادثات أو تضعه في أي ملف. احذف التوكن أو ألغِه من GitHub بعد الاشتباه في انكشافه.

## تشغيل محلي للمعاينة

يمكن فتح `docs/index.html` مباشرة، لكن فحص إعدادات الاتصال وPWA يحتاجان استضافة HTTP/HTTPS. لا يُنصح باعتبار الفتح المحلي اختبار نشر.
